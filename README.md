# PDF Signature Editor

Локальное GUI-приложение для размещения графических пресетов **подписи**,
**инициалов** и **« Lu et approuvé »** на страницах PDF. Документ никуда не
отправляется, а оригинал не перезаписывается.

## Возможности

- просмотр и навигация по всем страницам PDF;
- три графических пресета: подпись, инициалы и « Lu et approuvé »;
- сохранение выбранных PNG/JPG для следующих запусков;
- перетаскивание и изменение размера элементов;
- изменение размера картинки мышью за угловой маркер с сохранением пропорций;
- добавление произвольного текста;
- сохранение результата в новый обычный PDF.
- автоматический выбор языка интерфейса по системным настройкам.
- создание и импорт защищённого сертификата `.p12/.pfx`;
- необязательная криптографическая подпись итогового PDF.

Для пресетов лучше использовать PNG с прозрачным фоном.

## Язык интерфейса

Поддерживаются русский, французский и английский. При запуске приложение
использует основной язык macOS, Linux или Windows. Если язык системы пока не
поддерживается, используется английский. После изменения системного языка
перезапустите приложение.

## Установка на macOS

Дважды щёлкните `start-macos.command`. При первом запуске скрипт создаст
локальное Python-окружение и установит зависимости. Если macOS заблокирует
файл, выберите его правой кнопкой мыши и нажмите **Открыть**.

Установить через Terminal можно так:

```bash
chmod +x setup-macos.sh start-macos.command
./setup-macos.sh
./start-macos.command
```

Требуются Python 3 и Poppler (`brew install poppler`).

## Использование

1. Нажмите **Открыть PDF**.
2. При первом клике на пресет выберите соответствующий PNG/JPG. Файл будет
   скопирован в локальную библиотеку приложения.
3. Перетащите добавленный элемент мышью.
4. Выберите картинку и потяните красный маркер в её правом нижнем углу.
   Размер также можно настроить ползунком в боковой панели.
5. Нажмите **Сохранить как…**.

## Цифровая подпись

1. Нажмите **Сертификат…**.
2. Выберите существующий `.p12/.pfx` либо создайте локальный сертификат.
3. Включите **Подписать цифровой подписью** на верхней панели.
4. При сохранении введите пароль сертификата.

Пароль нигде не сохраняется. Подпись добавляется после всех визуальных
изменений, а итоговый файл повторно проверяется приложением. Самоподписанный
сертификат подтверждает целостность PDF, но программы чтения PDF не будут
автоматически считать личность владельца доверенной.

Клавиши со стрелками меняют страницу. `Delete` или `Backspace` удаляет
выбранный элемент. Кнопка `⋯` позволяет заменить изображение пресета.

## Запуск для разработки

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

Тесты:

```bash
.venv/bin/python -m pytest
```
