# PDF Signature Editor

Веб-сервис и локальное GUI-приложение для размещения графических пресетов
**подписи**, **инициалов** и **« Lu et approuvé »** на страницах PDF. Веб-версия
передаёт документ только на ваш сервер в локальной сети. Оригинал не
перезаписывается.

## Запуск на Synology через Container Manager

1. Склонируйте репозиторий в папку NAS, например
   `/volume1/docker/pdf-signature-editor`.
2. В Container Manager → **Проект** → **Создать** выберите эту папку и
   существующий файл `docker-compose.yml`. Запустите проект. Альтернатива через SSH:

   ```bash
   cd /volume1/docker/pdf-signature-editor
   docker compose up -d --build
   ```

3. Откройте `http://IP-АДРЕС-NAS:8057` в браузере устройства локальной сети.
   Если порт 8057 занят, измените левую часть `8057:8057` в `docker-compose.yml`.

Контейнер работает без учётных записей. Не настраивайте перенаправление порта
8057 из Интернета. Если на NAS включён брандмауэр, разрешите этот порт для
локальной подсети.

Загруженные PDF и изображения находятся во временной памяти контейнера,
удаляются после перезапуска и автоматически очищаются после 24 часов
неиспользования. Для временных файлов выделено до 512 МБ; лимит одной загрузки
— 50 МБ. Пресеты изображений сохраняются в хранилище конкретного браузера.
Настройка **Кто** позволяет хранить отдельные подпись, инициалы и «Lu et approuvé»
для каждого человека. Старые пресеты при обновлении попадут в профиль
**Основной**.
Сертификат и пароль используются только при экспорте; пароль не сохраняется.
Скачанный PDF и созданный сертификат сохраните на своём устройстве.

Проверка состояния сервиса: `http://IP-АДРЕС-NAS:8057/health`.

## Возможности

- просмотр и навигация по всем страницам PDF;
- три графических пресета: подпись, инициалы и « Lu et approuvé »;
- сохранение выбранных PNG/JPG для следующих запусков;
- перетаскивание и изменение размера элементов;
- изменение размера картинки мышью за угловой маркер с сохранением пропорций;
- добавление произвольного текста;
- сохранение результата в новый обычный PDF;
- создание и импорт защищённого сертификата `.p12/.pfx`;
- необязательная криптографическая подпись итогового PDF.

Для пресетов лучше использовать PNG с прозрачным фоном.

## Использование в браузере

1. Откройте PDF, выберите **Кто** и нужный пресет или добавьте текст. Для другого
   набора изображений нажмите **Добавить** рядом со списком **Кто**.
2. Перетащите элемент на нужное место. Размер изображения меняется за красный
   маркер или через поле «Ширина».
   Чтобы удалить элемент, нажмите × на нём или выберите его и нажмите Delete.
3. При необходимости выберите сертификат и включите цифровую подпись.
4. Нажмите **Скачать PDF**. Исходный документ останется без изменений.

## Язык локального GUI

Поддерживаются русский, французский и английский. При запуске приложение
использует основной язык macOS, Linux или Windows. Если язык системы пока не
поддерживается, используется английский. После изменения системного языка
перезапустите приложение.

## Установка на macOS

Дважды щёлкните `start-macos.command`. При первом запуске скрипт создаст
локальное Python-окружение и установит зависимости. Если macOS заблокирует
файл, выберите его правой кнопкой мыши и нажмите **Открыть**.

Установить через Terminal можно так:

```bash
chmod +x setup-macos.sh start-macos.command
./setup-macos.sh
./start-macos.command
```

Требуются Python 3 и Poppler (`brew install poppler`).

## Использование локального GUI

1. Нажмите **Открыть PDF** и выберите **Кто** в боковой панели. Там же можно
   добавить, переименовать или удалить набор изображений.
2. При первом клике на пресет выберите соответствующий PNG/JPG. Файл будет
   скопирован в локальную библиотеку приложения.
3. Перетащите добавленный элемент мышью.
4. Выберите картинку и потяните красный маркер в её правом нижнем углу.
   Размер также можно настроить ползунком в боковой панели.
5. Нажмите **Сохранить как…**.

## Цифровая подпись в локальном GUI

1. Нажмите **Сертификат…**.
2. Выберите существующий `.p12/.pfx` либо создайте локальный сертификат.
3. Включите **Подписать цифровой подписью** на верхней панели.
4. При сохранении введите пароль сертификата.

Пароль нигде не сохраняется. Подпись добавляется после всех визуальных
изменений, а итоговый файл повторно проверяется приложением. Самоподписанный
сертификат подтверждает целостность PDF, но программы чтения PDF не будут
автоматически считать личность владельца доверенной.

Клавиши со стрелками меняют страницу. `Delete` или `Backspace` удаляет
выбранный элемент. Кнопка `⋯` позволяет заменить изображение пресета.

## Запуск для разработки

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

Для разработки веб-версии и запуска всех тестов:

```bash
.venv/bin/pip install -r requirements-web.txt pytest
.venv/bin/python -m flask --app pdf_editor.web run --port 8057
.venv/bin/python -m pytest
```
